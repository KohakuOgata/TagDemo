# TagDemo — タグで管理するコンテンツブラウザ

ゲーム開発のアセットを **フォルダ階層ではなくタグ** で管理するアイデアのデモです。
Unreal Engine のコンテンツブラウザ風の UI で動作します。

## 動作

- 最初の画面には **タグが付いていないアセット** と **存在するすべてのタグ** が表示されます。
- タグをクリックすると、そのタグが選択中に加わります（フォルダに入る操作に相当）。
- タグを選択している間は次のものが表示されます。
  - 選択中のタグと **完全一致** するタグを持つアセット
  - 選択中のタグをすべて持つアセットに付いている、まだ選択されていないタグ（次に入れる「サブフォルダ」）
- 選択中のタグは上部に順不同のチップとして並び、`×` でそのタグだけを外せます。`All` で全て解除します。タグの順序は関係ありません。
- 選択状態は URL (`#tags=Environment,Rock`) に保存されるので、ブラウザの戻る/進むや共有ができます。

## 構成

ビルド不要の静的サイトです。

- `index.html` — 画面
- `css/style.css` — スタイル
- `js/data.js` — デモ用アセットデータ（ここを書き換えればアセットやタグを変更できます）
- `js/app.js` — タグ絞り込みロジックと描画

## GitHub Pages で公開する

リポジトリの **Settings → Pages** で、Source を "Deploy from a branch"、Branch を `main` / `(root)` にします。

ローカルで確認する場合:

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```
